# Android Quick Start Pack

This repository contains a curated folder list to make it easier for people who are setting up Android handhelds from scratch.

## What's Included

- Pre-configured folder structure for ROMs and system files  
- Obtainium APK (automatically updated via workflows)  
- Obtainium Emulation Pack for standard & dual-screen devices (automatically updated via workflows)  
- Mr Purple T26 & T28 Turnip drivers  
- ES-DE Folder structure (no ES-DE files included)  
- ES-DE custom system configurations by GlazedBelmont (automatically updated via workflows)

## Automated Workflows

This repository uses GitHub Actions to automatically update:

- ES-DE system configurations  
- Obtainium APK releases  
- Obtainium Emulation Pack
